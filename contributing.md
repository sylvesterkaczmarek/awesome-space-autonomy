# Contributing

Thanks for helping improve Awesome Space Autonomy.

This repository is curated. A resource being space-related is not enough for inclusion.

## What belongs here

Strong submissions usually do at least two of the following:

- contribute directly to autonomy in spacecraft, space robots, instruments, or distributed space systems;
- provide a primary paper, official standard, flight demonstration, maintained tool, benchmark, dataset, or reference implementation;
- support onboard decision-making, planning, execution, navigation, GNC, fault management, FDIR, onboard AI, autonomous science, distributed autonomy, robotic exploration, simulation, or autonomy V&V;
- contain enough documentation or evidence for another researcher or engineer to assess and use the work;
- have demonstrated technical relevance beyond a single promotional demo.

## What usually does not belong here

- generic space software with no meaningful autonomy connection;
- broad astrodynamics, satellite, or ground-segment resources that do not enable autonomy;
- duplicate resources already represented by a better primary source;
- abandoned repositories unless they are historically important;
- company marketing pages when a paper, mission page, standard, documentation page, or source repository is available;
- self-promotional submissions with unclear technical value.

## Pull request format

Add one resource per pull request when practical.

Use this format:

```markdown
- [Project or paper](https://example.com) - One sentence explaining its specific space-autonomy value.
```

The description should explain why the resource matters. Avoid superlatives, marketing language, and restating the title.

## Placement

Place the resource in the narrowest appropriate section. If none fits, propose a new section only when several strong resources would belong there.

## Quality checks

Before submitting:

1. Confirm the link resolves.
2. Prefer the primary source.
3. Check that the resource is not already listed.
4. Keep the description factual and concise.
5. Run `npx awesome-lint` if you have Node.js available.

## Conflicts of interest

You may submit your own work. State that clearly in the pull request. Self-authored resources are judged using the same criteria as other submissions.

## Maintenance

Resources may be removed when they become unavailable, misleading, superseded, abandoned without historical value, or no longer meet the editorial bar.
